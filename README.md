# GitHubPublic

个人公开作品总仓库。与私有工作区物理隔离，目录结构、路径与账号信息一律不外带。

## 约定

- 每个项目一个顶层子目录，子目录自带独立 README 与 LICENSE
- 仓库只放**成品**：源码、素材、文档。不放构建中间产物、缓存、凭据
- 凭据类文件（`.env`、`*.key`、`.credentials.yaml`、`*secret*`）在任何子项目里都不入库
- 文档里不出现本机绝对路径、盘符用户名或私有工作区名称，一律写相对路径或通用写法

## 隐私口径

从私有工作区复制任何东西进来之前，先过一遍：

- 绝对路径、盘符用户名、私有工作区目录名 → 一律改成相对路径或通用写法
- 真实姓名、联系人、账号 ID → 不带
- token / key / cookie / 凭据文件 → 不带
- 截图 → 私人文字必须模糊，通知条/提示条要么裁掉要么换素材

各子项目的 `.gitignore` 只排除明确可再生成的产物，不用 `*.png` 这类通配规则误伤正式资产。
